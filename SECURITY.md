# Security Policy

## Supported Versions

Security updates and dependency maintenance apply to the latest deployed version of this portfolio.

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability, exposed sensitive credential, or cross-site scripting issue in this repository or the live site (`atharveeee.vercel.app`), please disclose it responsibly:

1. **Do not file a public GitHub issue.**
2. Send an email directly to Atharve Dahima at `atharveeee@gmail.com`.
3. Include the following information:
   - Nature of the vulnerability (e.g. XSS, header misconfiguration, client-side injection)
   - Steps to reproduce or proof-of-concept payload
   - Potential impact on client browsers or Vercel edge endpoints

## Response Timeline

- **Acknowledgement:** Within 48 hours of initial receipt.
- **Triage & Remediation:** Within 5 business days for valid vulnerabilities.
- **Deployment:** Hotfix deployed directly to production on Vercel.
